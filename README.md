# ai-trip-planner

中文旅行攻略 · 从调研到上线一条龙。一个开源 ZCode / Claude Code 插件：**两阶段状态机**（选方案 → 细化）驱动 agent 端到端产出**特辑风网页攻略站**并部署上线。自驾、自由行、亲子出行皆宜。

## 30 秒安装

ZCode / Claude Code 里执行（本仓库同时是单插件 marketplace）：

```
/plugin marketplace add jerryjiao/ai-trip-planner
/plugin install ai-trip-planner@ai-trip-planner
```

装完跑 `/trip-doctor` 看环境健康矩阵，然后 `/trip-plan` 开第一个攻略。官网：https://jerryjiao.github.io/ai-trip-planner/环境引导与降级说明见 `skills/ai-trip-planner/references/setup.md`。

## 为什么存在

用 AI 做攻略，难的不是排行程，是真实世界：

- **平台有脾气**：点评进店要限量慢速、小红书有风控期、滑块一弹全停——额度与节奏要有人管。
- **数据通道有暗礁**：高德 key 分类型（拿错调接口就报错）、点评城市频道有独立 cityid、登录态有时效。
- **版式会返工**：全家看的是「旅游攻略」不是「App 界面」，风格定错一次，全站重写。
- **进度会丢**：跨会话接着干，谁也记不住上次查到哪。

这个插件把这些问题流程化：两阶段状态机管节奏、trip-state.md 管进度、**五个平台通道自动查**（下表）、十篇分域手册把踩过的坑固化成可执行知识、额度账本随用随记、缺件自动降级（没 key 也能跑完地图环节）。

## 五个平台自动查

| 平台 | 定什么 | 怎么查 |
|---|---|---|
| 小红书 | 玩法 / 避雷 / 动线（软情报） | 只读搜索，额度账本管节奏 |
| 大众点评 | 餐厅定店（硬数据） | 品类好评榜选店 + 进店实读全量 |
| 携程 | 住宿主查：档期价 / 房型 / 取消政策 | 详情实读 + **订房深链**（家人点开就是带好日期的订房页） |
| 飞猪 | 住宿比价 + 备用深链 | 同店交叉比价，价差如实标注 |
| 高德 | 车程 / 坐标 / 路线图（事实核验） | 零 key 基础层 + 可选 JSAPI 增强层 |

只读不代订：深链把家人送到订房页，下单永远你自己完成。

## 四个命令

| 命令 | 干什么 |
|---|---|
| `/trip-plan` | 总入口：新攻略摸底开做，老攻略自动续接进度 |
| `/trip-go <方案>` | 阶段门：拍板选定方案，轻页封存，进入逐天细化（「就选X」同效） |
| `/trip-doctor` | 体检：工具链、五平台登录态、额度账本，✅/⚠️/❌ 矩阵 + 补救指引 |
| `/trip-help` | 迷路导航：现在在哪、下一步干嘛 |

## 能力与降级矩阵

| 缺什么 | 自动降级到 | 影响 |
|---|---|---|
| 小红书登录态 | 搜索引擎间接源（攻略镜像页） | 软情报（玩法/避雷）质量略降 |
| 大众点评登录 | 搜索引擎公开快照 + 公开评价页 | 定店数据标注「未核实·建议 App 复核」 |
| 高德登录 | 基础查询不受影响；免 key 深链给手机导航 | 精细渲染需增强层 |
| 高德 key | 路线图走网页版整页截图 | 图面精细度略降 |
| 携程/飞猪登录 | 公开列表与档期价（未登录口径） | 住宿核价标「待核实」；订房深链不需要登录，不受影响 |
| wrangler | 本地静态站交付（http.server / zip） | 不上线，其余不变 |
| playwright | 五平台网页通道停用，WebFetch/搜索引擎兜底 | 按上表各行降级 |

核心流程（摸底 → 轻页拍板 → 版式样板 → 逐天闭环 → 全站自检 → 部署）在任何一行降级下都能走完。

## 交付版式

**攻略特辑风**：杂志式排版（通栏 hero、刊头、壹贰叁小节号、竖排逐时时间轴、编辑部表格、门票黄框、系列导航），六视口自适应（1440→360），手机上正文锚点直跳餐厅、导航按钮直唤高德。模板在 `templates/`（内容虚构占位，拷走即用）。

## 合规与边界

- **只读不代操作**：不代下单、不代付款、不代发布；小红书永久只查不发。
- **登录与验证交还用户**：扫码、滑块一律人工完成；触发风控即停。
- **额度参数是保守经验默认值**（非平台规则），可自行调整。
- 尊重各平台服务条款；本插件只做个人攻略场景的信息整理。
