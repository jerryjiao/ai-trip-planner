# /trip-doctor · 环境体检

你是 ai-trip-planner 插件的体检命令。对照 `skills/ai-trip-planner/references/setup.md` 的依赖总表逐项检查，输出健康矩阵。**空环境也必须能跑完不崩**：查不到就如实标 ❌/⚠️ 并给最小可用路径，不许因为缺件中断体检。

## 检查步骤

逐组执行，能并行的命令并行跑。每项判定规则：

### A. 工具链（Bash 直接查）

1. `node --version` → ✅ ≥18 / ⚠️ 更低版本 / ❌ 未装
2. `python3 --version` → ✅ ≥3.9 / ⚠️ 更低 / ❌ 未装
3. playwright：在当前目录 `node -e "import('playwright').then(()=>process.exit(0)).catch(()=>process.exit(1))"`；失败再看环境变量 `TRIP_PLAYWRIGHT_PATH` 是否指向存在的文件
4. `wrangler --version` → ✅ 有 / ❌ 无（⚠️ 级：可降级本地交付，不阻塞）
5. `gh --version` → ✅ 有 / ❌ 无（⚠️ 级：仅发布门用）

### B. 环境变量（Bash `echo $VAR` 查，全部可选）

- `XHS_USER_DATA_DIR`：设了且目录存在 → ✅；没设 → ✅（走默认目录 `~/.ai-trip-planner/xhs-profile`，目录存在即活）；设了但目录不存在 → ⚠️
- `TRIP_PLAYWRIGHT_PATH`：没设且默认解析成功 → ✅（注：默认解析）；指向的文件存在 → ✅；指向不存在 → ❌
- `AMAP_JSAPI_KEY`：有 → ✅（增强层可用）；无 → ✅（基础层足够，注明「增强层关闭」）

### C. 三平台登录态（能用浏览器自动化就实测，不能就轻探）

1. **大众点评**：打开 `https://www.dianping.com`，右上角有用户名 → ✅；要求登录 → ❌；无浏览器通道 → ⚠️（写明「未验证」与手动验证方法）
2. **高德**：打开 `https://ditu.amap.com`，右上角有账号名 → ✅；仅游客 → ⚠️（基础查询不受影响）
3. **小红书**：优先跑 `node <插件目录>/scripts/search_ro.mjs --probe`（只探登录态不搜索、不占额度）；无 node/playwright 时看登录态目录是否存在 → 存在 ⚠️ / 不在 ❌
4. 任一平台出现滑块/安全限制页面：**立即停**，该项标 ❌ 并注明「触发风控，需用户人工处理后复检」，不重试。

### D. 额度账本（有项目才查）

当前目录（或用户指明的攻略项目目录）有 `trip-state.md` 就读「额度账本」节，报今日已用/上限/剩余；没有项目 → 标 ✅（N/A，无在途项目）。

⚠️ wrangler 未装            影响：部署降级为本地静态站；补：npm i -g wrangler（setup·工具链表）

登录态
✅ 大众点评                 影响：硬数据定店
⚠️ 高德（游客）             影响：基础查询可用；登录更稳；补：ditu.amap.com 扫码（setup·登录态表）
❌ 小红书                   影响：软情报降级为搜索引擎间接源；补：跑 search_ro.mjs 扫码（setup·登录态表）

额度账本

规则：每个非 ✅ 项必须有「影响哪一步 + 去哪补」；总体结论给出**当前环境下直接可开工的最小路径**（哪怕全降级也要说清能走多远）。
