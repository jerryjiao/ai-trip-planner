# /trip-plan · 总入口

$ARGUMENTS

读 `skills/ai-trip-planner/SKILL.md` 按其流程执行：

- **当前目录有 `trip-state.md`** → 按 Step 0 续接：读状态、复述「上次到哪了」、继续当前阶段。
- **没有且用户要开新攻略** → 进阶段一：先摸底（时间/人数/构成/预算/出行方式与车程半径/偏好），需求不全不开工；然后研究先行 → 轻页 → 推荐，停下等拍板。
- **用户只带了模糊想法**（如「国庆想出去玩」）→ 摸底时帮他把候选目的地聊出来，再进研究先行。

不明确的地方一律先问再动手；额度与风控红线见 SKILL.md Constraints。
