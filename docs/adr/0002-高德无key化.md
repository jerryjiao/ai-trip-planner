# ADR 0002 · 高德通道无 key 化（基础层零门槛 + 增强层可选）

- 状态：已接受（2026-09-14）
- 影响：references/amap.md、scripts/amap-route.mjs、setup.md、/trip-doctor

## 背景

高德开放平台的 key 分类型（Web服务型 / Web端 JSAPI 型等），新手极易踩类型坑：拿 JSAPI 型 key 调 restapi 一律报 `10009 USERKEY_PLAT_NOMATCH`；JSAPI 还需要配套安全密钥（securityJsCode），且只认 `window._AMapSecurityConfig` 前置设置。key 门槛 + 类型坑让「第一次做攻略就先去申请 key」成为劝退点。

同时，攻略场景实际需要的地图能力有限：POI 评分/坐标、车程核数、路线图、手机导航深链。这些在**扫码登录高德网页版**后都有零 key 路径。

## 决策

**双层结构**：

- **基础层（默认，零 key）**：用户扫码登录网页版即可跑全流程。POI 走 www.amap.com 同源 poiInfo 接口旁路；车程走 ditu.amap.com/dir 网页版路线 UI（驾车/公交/步行）；路线图用路线结果页整页截图裁剪；手机导航用 uri.amap.com 免 key 深链。
- **增强层（可选）**：用户自配 Web端 JSAPI key（`AMAP_JSAPI_KEY` 环境变量）解锁精细路线图渲染（scripts/amap-route.mjs：编号标记、fitView、JSON 车程数据）。

## 权衡

- 整页截图 vs JSAPI 渲染：截图零门槛但精细度有限（文字小、起点易贴边）；JSAPI 渲染质量高但要 key。分层让默认路径零门槛、质量要求高的用户再上增强层。
- 备选「Leaflet + 高德瓦片」：保留为整页截图不达标时的后手（amap.md 已注明），不预先实现。
- 同源接口旁路的稳定性一般（间歇性挂起、偶发返回 HTML），手册写入 AbortController 超时与重试对策，换取免 key 与免登录 API。

## 后果

- 新用户十分钟起步路径成立（setup.md）：不申请任何 key 即可开工。
- 实测验证（2026-09-14）：基础层 ditu/dir 未登录自动化环境会弹登录+滑块浮层，**先扫码登录再查**是稳妥口径；增强层脚本端到端跑通（通用城市 11.5km/24min + 路线图）。
- securityJsCode 的坑写入手册：只认 `window._AMapSecurityConfig` 且须在 loader.js 前；`AMapLoader.load({securityJsCode})` 传了无效；模板语法错误会让配置静默失效。
