# dianping · 点评通道（硬数据定店）

> 阶段二「硬数据定店」的唯一准源。未登录基本搜不了，**先登录再取数**（红线，见 SKILL.md Constraints）。
> 记录铁律：每家店的数据标注 `大众点评实测 · YYYY-MM-DD`；查不到的字段标「待核实」，不许编。

## 1. 登录

- 登录页：`https://account.dianping.com/pclogin?redirUrl=https%3A%2F%2Fwww.dianping.com%2F`
- 页面显示「APP扫码登录」；二维码显示「已失效」时点「请点击刷新」再让用户扫。
- 用户扫完跳回 dianping.com，右上角出现用户名/头像即成功。
- **遇到登录墙/滑块/验证码：停下交给用户**，不代解、不绕过、不重试触发风控。
- 登录态在浏览器通道里会保持；每个会话第一次取数前先开一页确认还活着，失效就再走一次扫码。

## 2. 定位城市与 cityId（关键一步）

1. 直接访问城市页：`https://www.dianping.com/<拼音>`（如 `wuhan`、`xianyang`）。首页可能是精简页，别从首页点，直接进城市页。
2. 从页面 HTML 提取 cityId：正则 `cityId["']?\s*[:=]\s*["']?(\d+)`（例：乌鲁木齐 325、克拉玛依 326，这些是页面里公开的编号）。
3. **县级市有独立频道的坑**：部分县级市与上级地区是两个频道、两个 cityId（如「阿勒泰市」与「阿勒泰地区」不同号）。县城/乡镇的店通常归在上一级地区频道下。拿不准时两个频道都开一下，看哪个能搜到店。
4. 换城市不用点页面切换器，直接改 URL 拼音更稳。

## 3. 按品类选店（列表页）

- 搜索 URL 直达（比页面内点搜索稳）：

  ```
  https://www.dianping.com/search/keyword/{cityId}/0_{关键词URL编码}
  ```

- 关键词用**品类词**选池子（如「农家菜」「土菜馆」「面馆」），不是具体店名。
- 列表页每张卡片提取：店名、星级、评价数、人均、品类、区县/商圈、榜单徽标（如区域美食榜）。
- **选店口径**：星级 ≥4.5 且评价数几百条起步优先；看榜单徽标交叉印证；再按需求卡的预算档与人 群适配筛。
- 「按品类好评榜选店」的实操就是这个：品类词搜索 + 星级评价数排序 + 榜单徽标。列表页一次能看几十家，**这里不消耗进店额度**，池子尽量拉开品类广度（writing.md 餐厅梯度）。
- 不做美团交叉（美团网页版没有可用的搜索入口）；第二来源可用公开评价页参考，但必须标明平台，不与点评数据混写。

## 4. 进店实读 SOP（全量，每家店）

**一次进店把下面全部读完再走**，避免二次进店重复消耗额度：

| 读什么 | 要点 |
|---|---|
| 综合星级与分项 | 口味/环境/服务（有食材分项也记） |
| 评价数与人均 | 照抄数字，标核实日期 |
| 榜单徽标 | 有什么记什么（区域榜/必吃类） |
| 营业时间 | 逐段抄（含午市间歇、周末差异） |
| **全部在售套餐** | 名称/价格/适用人数/含什么；标注「几人份」是排计划的关键 |
| 推荐菜 | 菜名带「几人份」或份量口径 |
| **评价原文** | 必须翻到**含差评**的筛选取几条原文，提炼避雷点（等位/停车/口味翻车点），不许只看好评摘要 |

**产出格式**（写进当天页面与调研底稿）：

```
店名 | ★4.7 口味4.8/环境4.6/服务4.5 | 人均 ¥68 | 榜单：区域美食榜
套餐：土鸡煲双人餐 ¥168（2人份）｜...
推荐菜：竹筒饭（大份3-4人）｜...
营业时间：11:00-14:00, 17:00-21:00
差评提炼：高峰等位40分钟+；停车位少
来源：大众点评实测 · 2026-XX-XX
```

## 5. 风控与额度

- **永不批量**：进店是一家一家读的，任何「循环批量抓店」的想法直接打消（Out of Scope 红线）。
- **单店间隔**：店与店之间歇几秒，像人浏览的节奏。
- **连进限量（保守默认，可配）**：一个会话连进 ≤5-6 家、一天 ≤20 家。这是风控经验值不是平台规则；用户可调，但下调容易上调险。
- **滑块即停**：出现滑块/安全验证立即停全部点评操作，交用户手动处理；恢复后**单店慢速**继续，不恢复当日放弃该通道（降级见 setup.md）。
- **额度记账**：每进一家店，trip-state.md 额度账本「点评进店」+1，随用随记。

## 6. 坑

- 未登录口径实测（2026-09）：城市页能开（拿 cityId 没问题），但搜索/频道/榜单页一律 302 跳登录。**别拿未登录口径冒充实测**，缺登录就按 setup.md 降级。
- 搜不到店≠店不存在：县城店常在上级地区频道；也有网红店只在别的平台有收录，如实标「第三方源」或换店。
- 景区内餐饮人均普遍比市区贵 ¥10-30，属正常，写进计划别当避雷。
