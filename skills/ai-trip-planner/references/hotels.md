# hotels · 比价通道（携程/飞猪 · 比价定住宿）

> 口诀「比价定住宿」的准源：**携程主查，飞猪比价**。住宿是家庭攻略的第一硬需求——选店、档期价、取消政策在这条通道核完，产出里再放「订房深链」，家人点开就是带好日期的订房页。
> 记录铁律：住宿数据标注 `携程实测 · YYYY-MM-DD`（飞猪比价另标 `飞猪比价 · YYYY-MM-DD`）；查不到的字段标「待核实」，不许编。

## 0. 通道分工

- **携程 = 住宿主查口**：按商圈/地标选店 → 档期实读（房价/房型/取消政策）→ 出订房深链。
- **飞猪 = 比价与备用**：同店或同档交叉比价，价差与差异点（含早/含取消/会员价）如实记、标注平台，不与携程数据混写。
- **附带职责**：门票渠道参考（购票提示里列携程/飞猪为渠道之一，官方渠道优先口径见 amap.md）；配图源见 photos.md（Trip.com/携程攻略站图床）。
- **只读不代订**：深链生成后，下单、收藏、领券一律用户自己完成（只读红线）。

## 1. 登录

- 携程：打开 `www.ctrip.com` / `hotels.ctrip.com` 右上角登录（扫码或短信），**用户本人完成**。
- 飞猪：打开 `www.fliggy.com` / `hotel.fliggy.com` 右上角登录，走**淘宝账号**体系；淘宝侧改密会使登录态失效。
- 登录入口以页面实际为准，引导时只指路不代操作；遇登录墙/滑块/验证码：停下交给用户，不代解、不绕过。
- 登录态在浏览器通道里保持；每会话第一次取数前先开一页确认还活着。

## 2. 选店（列表页）

1. **档期先行**：先把入住/退房日期改成需求卡的真实档期再搜——默认日期的列表价是「今天入住价」，直接抄必错。
2. 携程酒店列表页按 城市 + 商圈/地标/店名关键词 筛；列表卡片提取：店名、档位（星级/民宿档）、评分、评分数、价位、位置口径。
3. **选店口径**：评分 ≥4.7 且评分数百条起优先；位置按行程动线定锚（首日到达晚/核心玩法半径）；构成适配硬筛——家庭房/两室/可加床/停车位，带老人看电梯与楼层。
4. 飞猪同步搜同店或同档：记价差与差异点（含早/含取消/会员价），标注 `飞猪比价 · 日期`。
5. 列表页浏览不消耗额度；**进详情页才计数**。

## 3. 档期实读 SOP（全量，每家店）

**一次进店把下面全部读完再走**，避免二次进店重复消耗额度：

| 读什么 | 要点 |
|---|---|
| 档期房价 | 确认日期选择器是真实档期；抄「几晚总价」不是单晚价 |
| 房型 | 家庭房/两室/可住人数/床型/加床；对应需求卡构成 |
| 取消政策 | 可退/限时退/不可退；不可退的写进行前清单提醒 |
| 评分与差评 | 翻到**含差评**的筛选取几条原文，提炼避雷（隔音/卫生/停车/照片与实物差），不许只看好评 |
| 位置核实 | 到核心玩法的距离口径，与 amap.md 车程交叉核 |

**产出格式**（写进 index 住处卡与调研底稿）：

```
店名（商圈口径） | ★4.8（评价数 X 百+） | 档期 ¥XXX / X 晚
房型：两室一厅（2大2老1小）｜取消：X 日前可退
避雷：临街房隔音一般，备注要院内房；停车免费
飞猪比价：同档 ¥XX 差价，含双早（飞猪比价 · YYYY-MM-DD）
来源：携程实测 · YYYY-MM-DD
```

## 4. 订房深链（交付物标配）

攻略 index 住处卡放「订房直达」按钮组（templates/zine 已内置），家人点开即到带好日期与店名的订房页，下单自己完成：

- **携程公式**（实测样式收编自真实项目验收链路；示例参数全部虚构）：

  ```
  https://hotels.ctrip.com/hotels/list/?cityId=<携程城市ID>&checkin=<YYYY-MM-DD>&checkout=<YYYY-MM-DD>&crn=1&searchType=H&searchWord=<店名URL编码>
  ```

- **飞猪**：网页版搜到目标列表页后**直接复制当前 URL**（所见即所得）。参数手拼格式待实测收编，收编前不手拼。
- 日期必须与需求卡一致；改档期要重新生成深链，并逐条复验能打开（URL 校验见 pitfalls.md）。
- 深链本身不需要登录态，未登录降级时照常可出。

## 5. 风控与额度

- **额度账本新增两行**（保守默认，可配）：携程详情 ≤10 次/天、飞猪详情 ≤10 次/天；列表浏览不计数，详情/报价页一次 +1，随用随记。
- 页与页之间歇几秒，像人浏览的节奏；**永不批量**循环抓店。
- **滑块即停**：出现滑块/安全验证立即停全部比价通道操作，交用户处理；恢复后单页慢速继续，当日不恢复就放弃该通道（降级见 setup.md）。
- 不代下单、不代收藏、不代领券、不代比价后跳转支付。

## 6. 降级

- **无登录态**：公开列表与档期价多数可见，产出标「未登录口径 · 待核实」，出行前 App 复核。
- **无浏览器通道**：搜索引擎公开页兜底 + 让用户 App 自查截图；订房深链照常可出（不需要登录）。

## 7. 坑

- **默认日期陷阱**：所有列表价默认「今天入住」，先改档期再读，产出标注档期。
- 携程部分页面弹「打开 App」引导：留在浏览器通道，别跟跳。
- 同店异名：携程/飞猪/点评三家店名常有别名，比对以地址 + 品牌为准，不硬凑。
- 节假日价格波动大：核实价标注日期，行前清单提醒复验房价与取消政策。
- 飞猪价常含会员/红包差异：只记「可见价 + 差异点」，不猜用户实际到手价。
