# xiaohongshu · 小红书通道（软情报定玩法）

> 只读搜索，**永久红线：只查不发**。本通道给攻略吸收真实玩法经验（动线/时段/避雷/野路子），不给任何发布、点赞、评论、关注行为。

## 通道构成

- **脚本**：`scripts/search_ro.mjs`（单词）/ `search_ro_batch.mjs`（批量，词间 8-15 秒随机间隔，触发风控立即中止）。
- **登录态**：独立浏览器目录，环境变量 `XHS_USER_DATA_DIR`（默认 `~/.ai-trip-planner/xhs-profile`）。首次 `node search_ro.mjs --login` 扫码，登录态会记住；已有别的工具（如 xiaohongshu-driver）登录态的机器，把变量指过去直接复用。
- **登录/扫码永远用户本人完成**，脚本与 agent 不代操作。

## 额度政策（保守默认，可配置）

| 项 | 默认 | 说明 |
|---|---|---|
| 每日搜索上限 | ≤10 次 | 风控经验值，不是平台规则；紧张时可下调，不建议上调 |
| 单会话上限 | ≤5 次 | 跨天重置；批量脚本词数=次数，跑前先看账本 |
| 词间隔 | 8-15 秒随机 | 批量脚本已内置 |

**额度账本记法**（trip-state.md 的「额度账本」节，随用随记）：

```
额度账本:
  小红书搜索: {今日: 2026-09-14, 已用: 2, 上限: 10, 剩余: 8}
  点评进店:   {今日: 2026-09-14, 已用: 3, 上限: 20, 剩余: 17}
```

日期一变就重置归档。每次真实搜索（含批量里的每个词）+1，**用满就停，不靠运气**。

## 搜索结果的用法

- 列表页拿到的是 标题/作者/赞数/链接。**读笔记正文不占额度**：把链接交给网页阅读工具（webReader / WebFetch）读全文，想读几篇读几篇。
- **xsec_token 时效坑**：笔记链接带 `xsec_token`，会过期。过期后页面打不开，要重新搜索拿新链接=再烧 1 次额度。所以**当次搜索后趁链接新鲜把要读的正文读完**，别隔天再读。
- 软情报进攻略要消化后写（writing.md），不许整段抄笔记。

## 风控信号与处置

- 出现「安全限制」页 / 「IP存在风险」：**立即停用小红书通道**，当日不再试，脚本会自动中止剩余词。
- 处置：当日退搜索引擎间接源；次日先 `--probe` 确认恢复，恢复后单次慢速。
- **触发风控不重试、不换号、不代解**，这是账号安全问题，交给用户判断。

## 降级：搜索引擎间接源

无登录态 / 封禁期 / 额度用满时：

- `site:xiaohongshu.com <关键词>`：搜索引擎能捞到部分笔记的标题与快照。
- 攻略镜像页：Trip.com 的目的地攻略页大量转述小红书玩法（事实上的镜像），马蜂窝、知乎补位。
- 降级口径如实标注来源（间接源），不冒充小红书原文。

## 坑

- 登录态是浏览器目录级共享：两个工具同时用同一个目录开会互相踢，一次只开一个。
- `--probe` 不占额度（只探登录态），`/trip-doctor` 用的就是它。
- 批量脚本跑一半中止时，已完成的词照常计入额度账本。
