# templates · 模板组使用说明

三套模板，**内容全部虚构占位**（虚构目的地「云溪谷」），拷走后替换成真实内容。任何模板都不引外部依赖（无 CDN、无框架），断网也能开。

## zine · 特辑风攻略壳（阶段二主线交付版式）

```
templates/zine/
├── index.html   总览页：刊头/hero/日卡/住处/预算/装备清单（勾选自动记忆）
├── day.html     日页：今日动线/逐时安排/车程/门票黄框/餐厅卡（首选+备选）/实拍贴士/系列导航
└── zine.css     共用样式（六视口自适应：宽屏→900 以下表格横滑→640 以下单列）
```

起步：
1. 整目录拷进攻略项目（如 `site/`），改 `<title>`、刊头、hero 三处。
2. hero 配图：`img/hero.jpg`（1600×900 横图）放好后，给 hero div 加 `has-img` 类、删占位行。
3. 多天页面：复制 `day.html` 改名 `day1.html`、`day2.html`…，series 导航互链，index 日卡指过去。
4. 实拍图放进 `img/`，替换 `imgph` 占位块；**逐张看内容再配图注**（photos.md 铁律）。
5. 路线图：`scripts/amap-route.mjs` 产物 `route.png` 直接嵌，或高德截图，图注写清来源与日期。

## lite · 方案轻页壳（阶段一拍板用）

```
templates/lite/index.html   单文件：需求卡摘要/方案对比表/目的地共识/推荐与拍板方式
```

起步：拷进项目（如 `plans/`），一列一方案填决策级数据（车程/住宿可得/吸引点/门票档/粗预算），共识区标来源。拍板后此页封存不再改。

## trip-state.template.md · 状态文件模板

拷进攻略项目根目录改名 `trip-state.md`，七节齐全（阶段/需求卡/方案/逐天进度/额度账本/遗留/部署）。每会话 Step 0 先读它；状态变化当场写回。

## 隐私红线

模板与示例内容保持虚构。真实行程信息只存在于**你的攻略项目目录**，永不进本插件仓库。
