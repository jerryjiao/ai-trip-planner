叁五个平台自动查

每家平台管一类事实，agent 按口诀逐层核数：软情报定玩法 → 硬数据定店 → 比价定住宿 → 地图定事实。
平台定什么怎么查
小红书玩法 / 避雷 / 动线（软情报）只读搜索，额度账本管节奏
大众点评餐厅定店（硬数据）品类好评榜选店 + 进店实读全量
携程住宿主查：档期价 / 房型 / 取消政策详情实读 + 订房深链
飞猪住宿比价 + 备用深链同店交叉比价，价差如实标注
高德车程 / 坐标 / 路线图（事实核验）零 key 基础层 + 可选增强层
订房深链：查好的住宿直接生成带日期与店名的订房页链接，嵌在攻略住处卡里，家人点一下就到订房页——下单仍由你自己完成，插件只读不代订。

肆缺件不废流程

降级矩阵：缺什么就换哪条通道，核心流程都能走完。
缺什么自动降级到影响
小红书登录态搜索引擎间接源软情报质量略降
点评登录公开快照 + 公开评价页定店标「未核实」
携程/飞猪登录公开列表与档期价（未登录口径）住宿核价标「待核实」；订房深链不受影响
高德 key网页版整页截图路线图精细度略降
wrangler本地静态站交付不上线，其余不变

陆边界

只读不代操作：不代下单、不代付款、不代发布；小红书永久只查不发。
登录与验证交还用户：扫码、滑块人工完成，触发风控即停。
额度是保守经验默认（非平台规则），可自行调整。尊重各平台服务条款。
